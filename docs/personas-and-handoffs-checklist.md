# Personas & Handoffs — Checklist

Purpose: Provide a concise checklist to ensure key cross-functional handoffs are completed before work moves between phases.

Pre-Kickoff
- [ ] PdM documents problem statement, success metrics, and target users
- [ ] Stakeholder list identified (including CSM, Security, Design, Support)

Design & Planning
- [ ] UX Designer review completed (wireframes/prototypes attached)
- [ ] Security/Compliance Lead initial risk review completed
- [ ] Acceptance criteria include usability and security checks
- [ ] Technical Writer assigned to draft docs and release notes

Implementation
- [ ] Design assets and specs handed to Developers (design-to-dev handoff)
- [ ] Security checklist integrated into the backlog item (scans, threat model)
- [ ] Docs-first or docs-alongside-implementation approach tracked

Pre-Release / Release
- [ ] QA verification completed (functional + usability smoke)
- [ ] Security scans and compliance evidence completed
- [ ] Technical Writer final draft ready and linked in PR
- [ ] CSM notified for customer pilots or communications
- [ ] Release readiness signoff from PM, PdM, and Security Lead

Post-Release
- [ ] Adoption metrics assigned and monitored (owner: CSM/PdM)
- [ ] Post-release retrospective scheduled and action items assigned
- [ ] Documentation and support materials updated as needed
